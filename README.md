# Assignment 11

## Question

Design a library system in Java or Python with:

- A base or abstract class LibraryItem with common fields like title and year
- An abstract or common method displayInfo()

Create subclasses such as:

- Book: add author
- DVD: add duration or genre

Your implementation should clearly show:

- Use of abstraction through a common structure in the base class
- Method overriding in subclasses
- Polymorphism using a collection of LibraryItem objects
- One additional feature: constructor overloading/default arguments or a class/static counter
