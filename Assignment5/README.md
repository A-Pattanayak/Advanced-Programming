# Simple Todo App

A simple React todo application built with Parcel and Tailwind CSS.

The app lets users add daily tasks, view them in a table, mark tasks as done or undo them, and delete tasks from the list. It uses React functional components and `useState` to manage the todo data.

## Tech Stack

- React
- Parcel
- Tailwind CSS

## Run Locally

```bash
npm install
npm start
```

Open `http://localhost:1234` in your browser.
